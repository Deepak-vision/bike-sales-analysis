# Bike Sales Analysis

An Excel-based Bike Sales Analysis project focused on analyzing sales performance, customer trends, and product insights.

## Project Overview

- Cleaned and analyzed bike sales data using Microsoft Excel.
- Created Pivot Tables for sales and category-wise analysis.
- Used charts and visualizations to identify important sales trends.
- Analyzed factors such as bike size, color, product category, and sales performance.
- Created a structured analysis report based on the dataset.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Functions
- Data Cleaning
- Data Visualization

## Project Files

- `Bike_Sales_Analysis.xlsx` – Excel dataset, analysis and charts
- `Bike_Sales_Report.docx` – Detailed project report
